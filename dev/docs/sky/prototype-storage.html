① 按域分库 每个 domain 一个 .db

不是一个大库。每个域独立 stores/<domain>.db，域内两张表：items（业务）+ domain_audit（审计，内嵌同库 → 天然同事务）。点击查看表结构。

② Filter 查询 补全 sky 的 query 全扫描

sky 的 query() 只全扫描 + limit，忽略 filter。Polaris 要补全：把 q.filter 解析成真实 WHERE。选一个域，输入 filter 看生成的 SQL。
-- 生成后展示 WHERE 子句

③ 事务与审计 补全 sky 的事务空操作

sky 的 begin() 是空操作（commit/rollback 不真生效）。Polaris 要真实事务：BEGIN IMMEDIATE，审计在事务内写入，rollback 则审计也不落库。

④ 仓库替换 命令层零改动

三个 unified 仓库（todo/requirement/scheduler）内部从 JSON 文件切到 SqliteStorage，公开 API（new(config_dir, workspace) + list/get/create/update/delete）不变 → 命令层无感知。

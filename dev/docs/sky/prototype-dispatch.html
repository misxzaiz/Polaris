① dispatch 全链路 所有调用统一走一条总线

所有调用（IPC / Web / 插件间）构造 Envelope 走 RouterBus::dispatch。权限 gate 是唯一入口，Source 由传输层注入、调用方不可自填。点击步骤查看说明，或点"运行一次"看全链路。

② 能力注册表 + dispatch 测试台 路由键是能力 id，不是插件名

RouterBus 持有 handles 注册表。选一个能力、选来源、填 payload，看权限裁决与 Reply。权限 gate 对 Source::Remote 严格（token 默认开）。

③ 事件流（复用 EventBroadcaster）不照抄 sky，它抄的是我们

dispatch 全程广播 dispatch.start → dispatch.end（或 dispatch.deny）。事件经现有 EventBroadcaster（2000 条/8MB 双上限 + gap 检测）注入 seq 后推送到 WS。这里展示订阅 Filter 只收到匹配事件。

本步只是让 RouterBus 骨架先存在并单测验证，382 个 command 不动。第四步才一块块把命令迁到 dispatch。

# AI 驱动 3D 建模 & 动画

> 让 AI 去操作建模工具，生成可爱的卡通小人 / 小动物 / 角色，并支持动作动画。
> 目标：低配置机器可流畅运行，建模观感达标（卡通风格，无需真实感）。

## 核心结论（速览）

| 项 | 结论 |
|----|------|
| **选型** | Blender（建模 + 自动绑定 + 预设动作）+ Three.js 前端预览 |
| **AI 角色** | AI 生成 Blender Python (bpy) 脚本，工具执行建模 |
| **风格** | 低多边形 Q 版卡通（人体/四足/宠物模板） |
| **动画** | 固定骨架模板 + 预设动作库，避免 AI 逐帧调动画 |
| **导出** | glTF / FBX（可进游戏引擎、VRM 播动画） |
| **配置要求** | 中低，Blender headless CPU 可跑，无需独立显卡 |

## 关键决策理由

1. **动画是分水岭**：程序化拼装（Three.js/Manifold）建模好做但动画做不了，骨骼绑定/蒙皮/动画曲线必须靠专业软件。
2. **Blender 免费全能**：唯一免费、建模/绑定/动画全覆盖、AI 好操作（bpy）的选项。
3. **避免 AI 调动画**：AI 逐帧调骨骼动画易翻车，改用「模板骨架 + 预设动作库」，AI 只选动作调参数。
4. **可接受安装**：需要 Blender 软件（~500MB），CPU 即可，无需 GPU。

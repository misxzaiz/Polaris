# 波音 747 参数化建模可行性分析

> 用 Blender bpy 脚本从零建模高真实度波音 747，并支持控制面/起落架等动画。
> 基于现有 Blender bpy 管线（Phase 1 已验证），但建模策略从 Q 版拼装升级为精确曲面造型。

---

## 1. 核心判断

**结论：可行，但需要调整建模策略——把 747 分解为可参数化的几何块，用曲线/曲面/细分建模，而非几何体拼装。**

| 维度 | 评估 |
|------|------|
| 机身主体 | ✅ 可用旋转体（Lathe / Spin）生成，参数控制长度/直径/锥度 |
| 机翼（含翼型） | ✅ 可用截面放样（Loft / Bridge Edge Loops），精度可达真实翼型 |
| 发动机 | ✅ 短舱+风扇叶片，参数化可控 |
| 尾翼/垂尾 | ✅ 类似机翼，截面放样 |
| 起落架 | ✅ 可用几何体拼装 + 父子层级 |
| 控制面动画 | ✅ 用 Armature（骨骼）或简单旋转，非角色骨骼，无蒙皮问题 |
| 涂装/贴图 | ⚠️ 需要外部纹理，脚本无法生成复杂涂装，建议用 UV 映射 + 基础色块 |
| 整体真实度 | ⭐⭐⭐⭐ 可达到"游戏级"（不输 FSX/P3D 默认机模），不及照片级 |

---

## 2. 建模策略

### 2.1 与 Q 版角色的关键区别

| 维度 | Q 版角色（现有方案） | 真实 747（本方案） |
|------|---------------------|-------------------|
| 建模方法 | UV 球体 + 圆柱 + 盒子拼装 | 曲线/曲面放样 + 细分 + 布尔 |
| 精细度 | ~5000 面 | ~50k-200k 面（可配 LOD） |
| 对称性 | 不对称（五官、表情） | 左右对称（可镜像） |
| 动画 | 角色骨骼 + 蒙皮 | 控制面旋转 + 变换，无蒙皮 |
| 材质 | 纯色 Toon | 金属/玻璃/涂装多层 PBR |
| 难点 | 拼接自然 | 比例精确、曲面光滑、细节丰富 |

### 2.2 推荐建模路径

```
┌─────────────────────────────────────────────────────┐
│                     Layer 1：基础外形                  │
│  机身（旋转体） → 机翼（放样） → 尾翼 → 发动机短舱      │
│  全部用 bpy 曲线/网格建模，Subdivision Surface 圆滑   │
├─────────────────────────────────────────────────────┤
│                     Layer 2：细节                     │
│  窗户（布尔阵列） → 舱门 → 面板线 → 起落架舱门         │
│  发动机风扇 → 翼尖小翼 → 静压孔/天线等                  │
├─────────────────────────────────────────────────────┤
│                     Layer 3：材质/涂装                 │
│  机身白漆（Principled BSDF）                          │
│  发动机金属（拉丝金属） → 驾驶舱玻璃（透明）             │
│  波音蓝/红涂装条纹（UV 映射或顶点色）                   │
├─────────────────────────────────────────────────────┤
│                     Layer 4：动画                     │
│  副翼/升降舵/方向舵（旋转）                             │
│  襟翼/缝翼（平移+旋转）                                │
│  起落架收放（层级变换 + 旋转）                          │
│  发动机风扇转动（旋转）                                 │
└─────────────────────────────────────────────────────┘
```

### 2.3 参数化设计

核心参数化，AI 可调、用户可改：

```python
params = {
    # 机身
    "fuselage_length": 70.6,      # 米（实际 747-400 约 70.6m）
    "fuselage_diameter": 6.5,     # 米
    "nose_taper": 0.3,            # 鼻锥锥度
    "tail_taper": 0.15,           # 尾部锥度

    # 机翼
    "wingspan": 64.4,             # 米（747-400 翼展）
    "wing_sweep": 37.5,           # 后掠角（度）
    "wing_root_chord": 10.0,      # 翼根弦长
    "wing_tip_chord": 2.5,        # 翼尖弦长
    "airfoil_type": "b747",       # 翼型（可配不同截面）

    # 发动机
    "engine_count": 4,
    "engine_diameter": 2.5,       # 风扇直径
    "engine_length": 4.0,         # 短舱长度
    "engine_position": [-1.5, -2.0, 1.5, 2.0],  # 展向位置

    # 细节
    "window_count": 60,           # 舷窗数量
    "has_winglets": False,        # 747 无翼尖小翼（747-400 有）
    "gear_deployed": True,        # 起落架初始状态
}
```

## 3. 动画可行性

### 3.1 控制面动画

747 的所有控制面都是**刚性旋转/平移**，不需要骨骼蒙皮，用 Object 变换 + 关键帧即可：

| 控制面 | 动作 | 实现方式 | 难度 |
|--------|------|----------|------|
| 副翼 (Aileron) | 上下偏转 ±25° | 绕 X 轴旋转子物体 | ⭐ |
| 升降舵 (Elevator) | 上下偏转 ±30° | 绕 X 轴旋转子物体 | ⭐ |
| 方向舵 (Rudder) | 左右偏转 ±30° | 绕 Z 轴旋转子物体 | ⭐ |
| 襟翼 (Flaps) | 后伸 + 下偏 0-40° | 平移 + 旋转组合 | ⭐⭐ |
| 缝翼 (Slats) | 前伸 | 平移 | ⭐ |
| 扰流板 (Spoilers) | 上翻 0-60° | 绕铰链线旋转 | ⭐⭐ |
| 起落架 (Landing Gear) | 收放 | 层级变换链条 | ⭐⭐⭐ |
| 发动机风扇 (Fan) | 旋转 | 绕 Y 轴旋转 | ⭐ |

### 3.2 动画存储

与现有方案一致：存为 Blender Action 数据，glTF 导出时 `export_animations=True`，Three.js 用 AnimationMixer 播放。

### 3.3 动画控制方式

AI 不逐帧调动画，而是通过**参数化动作**：

```python
action_params = {
    "action": "flaps_deploy",
    "flap_angle": 25,         # 襟翼角度（度）
    "speed": 1.0,             # 速度系数
    "synchronized": True,     # 同步/异步
}
```

预置动作集：

| 动作 | 类型 | 说明 |
|------|------|------|
| `idle` | 循环 | 所有控制面归零，风扇慢转 |
| `flaps_takeoff` | 一次性 | 襟翼放到 10°（起飞位） |
| `flaps_landing` | 一次性 | 襟翼放到 30°（着陆位） |
| `gear_retract` | 一次性 | 起落架收起 |
| `gear_deploy` | 一次性 | 起落架放下 |
| `roll_left` / `roll_right` | 一次性 | 副翼偏转 |
| `pitch_up` / `pitch_down` | 一次性 | 升降舵偏转 |
| `yaw_left` / `yaw_right` | 一次性 | 方向舵偏转 |
| `spoilers_deploy` | 一次性 | 扰流板打开 |
| `engine_spool` | 循环 | 风扇转速变化 |
| `takeoff_sequence` | 组合 | 起飞动作序列（松刹车→推力→抬轮→收轮） |
| `landing_sequence` | 组合 | 着陆动作序列（放轮→放襟翼→接地→反推→扰流板） |

## 4. 技术难点与风险

### 4.1 难点

| 难点 | 等级 | 缓解策略 |
|------|------|----------|
| 翼型截面精确建模 | 中 | 使用 NACA 翼型坐标表（公开数据），bpy 导入曲线 |
| 机身曲面光滑连续 | 低 | Subdivision Surface + 边缘折痕 (Crease) 控制 |
| 发动机吊舱与机翼融合 | 中 | 手动造型 + 布尔运算 + 桥接 |
| 起落架结构复杂 | 高 | 简化结构（支柱 + 轮轴 + 4 轮 bogie），不模拟真实减震支柱 |
| 涂装条纹（波音蓝/红） | 中 | UV 映射 + 基础纹理，或使用顶点色 + 颜色渐变节点 |
| 驾驶舱玻璃（透明） | 低 | Principled BSDF 透明度 + IOR 1.5 |
| 面部数量控制 | 低 | 按需调整 Subdivision 级别，LOD 策略 |

### 4.2 风险

| 风险 | 等级 | 说明 |
|------|------|------|
| bpy 脚本过长 | 中 | 全机脚本预计 500-1500 行，需拆分模块 |
| 调试困难 | 中 | 头执行无可视化，需迭代调整参数 |
| 生成时间 | 低 | 预计 1-5 秒，比 Q 版角色（0.13s）长但在可接受范围 |
| 模型真实度不达预期 | 中 | 纯脚本建模无法达到手工建模的细节水平，需管理预期 |

## 5. 实施计划（建议）

### Phase A：核心外形（~2 天）

```
1. 机身旋转体（Spin 修改器或旋转曲面）
2. 机翼放样（NACA 翼型 + 桥接面）
3. 尾翼（垂尾 + 平尾）
4. 4 台发动机（短舱 + 风扇 + 吊架）
5. 对称镜像（MIRROR 修改器）
```

### Phase B：细节（~2 天）

```
1. 舷窗阵列（布尔挖孔）
2. 舱门（客舱门 x 10 + 货舱门）
3. 驾驶舱玻璃
4. 起落架（前起落架 + 主起落架 x 4）
5. 控制面（副翼/襟翼/升降舵/方向舵/扰流板）
6. 翼尖/APU 排气口/天线
```

### Phase C：材质与涂装（~1 天）

```
1. 机身 PBR 材质（白漆 + 金属 + 玻璃）
2. 波音蓝/红涂装条纹（UV 映射 + 纹理或节点）
3. 发动机金属材质
4. 磨损/旧化（可选）
```

### Phase D：动画（~1 天）

```
1. 控制面旋转动画（副翼/升降舵/方向舵）
2. 襟翼/缝翼收放
3. 扰流板
4. 起落架收放（父子层级动画）
5. 发动机风扇转动
6. 组合动作（起飞/着陆序列）
```

### Phase E：导出与预览（~0.5 天）

```
1. glTF 导出（含动画）
2. 更新 Three.js 预览（添加控制面板）
3. 性能优化（LOD / 面数控制）
```

## 6. 与现有管线的兼容性

| 现有组件 | 兼容性 | 说明 |
|----------|--------|------|
| `run_blender.sh` | ✅ | 无需修改，直接执行 bpy 脚本 |
| Three.js 预览 (`preview.html`) | ✅ 需扩展 | 动画控制面板需增加控制面/起落架按钮 |
| 模板骨架 | ❌ 不适用 | 747 不使用角色骨骼，改用 Object 变换动画 |
| 预设动作库 | ✅ 类似 | 改为存 747 控制面动作，结构相同 |
| 导出流程 | ✅ | 相同 glTF 导出，`export_animations=True` |

# Battle Mode — 为学习而战

> 一种对抗式学习方法:通过有规则的辩论,把「分歧」变成「学习燃料」。
> 核心理念:**赢的标准不是谁说服了谁,而是谁在这个过程中成长了。**

---

## 0. 一句话定义

两个立场对立的辩手,在一个主持人控场下,对同一争议点进行带证据的交锋;
结束时产出共识/分歧/学习点,而非产出「胜负」。

**与其他辩论的本质区别**:死撑不认输 = 扣分;被证据打动后改立场 = 加分。

---

## 1. 角色

| 角色 | 职责 | 人数 |
|---|---|---|
| 辩手 A / B | 持对立立场,举证据,扛压力,可以被说服 | 2(可多对多) |
| 主持人 | 控节奏、判火力、记分、出「最狠一击」 | 1(默认 AI,可换人) |
| 观众 | 随时插话提问,被点名一方必须先答 | 0-N |

---

## 2. 回合流程(一个话题 6 阶段)

```
Phase 0  立题     定义争议点 + 双方立场 + 胜负标准(赢 = 学到什么)
Phase 1  立论     A/B 各一轮:核心论点 必须带证据,禁止空谈
Phase 2  交锋     2-3 轮:反驳 → 辩护 → 换角度再打
Phase 3  压力测试  主持人出「全场最狠一击」,双方轮流扛
Phase 4  总结     A/B 各一轮:「我承认 / 我坚持 / 我学到」
Phase 5  复盘     共识 · 分歧 · MVP论点 · 学习点 · 下一步
```

---

## 3. 硬规则(防打烂)

1. **举证义务**:论点必须带证据(代码/数据/文档/实例)。纯断言 → 无效。
2. **正面回应**:对方最强论点必须正面回答「我同意 / 我反对,因为 X」,不许绕。
3. **可认输**:任意轮可宣布「这点我被说服了」→ 对方得分,**认输者得诚实分**。
   这是学习模式的灵魂。
4. **禁偷换**:不许改定义、不许攻击人、不许只用「冷枪」逃避「重炮」。
5. **平局合法**:允许「分歧成立,各自保留」,不强制判负。

---

## 4. 火力分级(趣味机制)

- **重炮** 🔥:正面轰对方核心论点。分值高,风险高(轰空扣分)。
- **冷枪** 🪃:攻对手论证的边角漏洞。稳妥,分值低。
- 主持人裁定每次出招的火力类型。

其它趣味件:
- **观众空袭** 📢:观众插话,被点名一方必须 3 秒内停下论证先回答问题。
- **血条** ❤️:每轮结束显示双方「论点存活/被击破」统计。
- **MVP 论点评选** 🏆:复盘投票,选本场最有启发的一个论点,记入战绩。

---

## 5. 评分(学习模式的特有权重)

| 维度 | 权重 | 说明 |
|---|---|---|
| 论点质量 | 50% | 证据强度 + 逻辑连贯 |
| 承压表现 | 25% | 正面回应、不绕弯 |
| 学习性 | 25% | 被说服就认输、立场会修正 ← 别的辩论没有的分 |

> 一场 0 分但全程诚实认错的辩论,比一场 100 分但死守错误立场的辩论
> 更有学习价值。评分器永远记住这一点。

---

## 6. 产出物(battle 结束必须交)

1. **共识清单** — 以为会吵、其实两边早同意的东西
2. **真实分歧** — 收敛到最少的几条核心分歧
3. **本场学到的 3 件事**
4. **可执行下一步** — 把讨论落成行动

---

## 7. 档案

每场 battle 结束后,写入档案文件,可回看复盘:

```
docs/battle-archive/<YYYY-MM-DD>-<topic-slug>.md
```

档案结构:
- 元信息(日期、话题、双方、主持人、时长)
- 各阶段纪要(立论/交锋/压力测试的要点)
- 共识 / 分歧 / 学习点
- 火力使用记录 + 血条变化
- MVP 论点 + 评分

---

## 8. 话题来源

- 项目里的真实争议(架构取舍、bug 根因、方案选型)
- 用户正在学的任何知识点(技术/产品/通识)
- 双方的任意立场对抗(可约定「反方立场」强制扮演,练思考肌肉)

---

*Battle Mode v0.1 — 规则可被战斗本身修改。每场复盘如果发现规则有漏洞,先改规则,再改玩法。*

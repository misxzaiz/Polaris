## 四、阶段 1b：命令层接入（✅ 已完成 2026-09-27）

### 目标

把已就绪的 `SessionMessageDb` 通过命令层暴露给前端，前端 `src/session-v2/` 增加
`V2MessageLog`（调后端命令），打通「前端 session-v2 内核 → 后端 SQLite 消息日志」全链路。
**不修改任何现有业务路径**（旧 JSONL 存储不受影响，影子运行原则）。

### 关键设计

1. **全局单例**：`SESSION_DB: Mutex<Option<Arc<SessionMessageDb>>>`，懒初始化，`db()` 返回 Arc 克隆（规避 `OnceLock::take` unstable 与 `get_or_try_init` unstable 限制）
2. **双通道**：Tauri command + Web IPC 桥共用 inner 实现（对齐 dialog_storage 模式），前端统一 transport 自动适配
3. **参数契约**：后端 `MessageEntry` `#[serde(rename_all = "camelCase")]`，前端 `V2MessageLog` 传完整 entry 对象，camelCase 对齐

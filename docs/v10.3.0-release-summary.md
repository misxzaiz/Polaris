## 主题系统重构（核心变更）

### Spider-Man 沉浸式主题
- 全新 Spider-Man 沉浸式主题 `eb587538`
- 蓝调增强，红蓝黑三色平衡 `8251ba1a`
- 主题配置完善：UI 密度与聊天字体大小设置 `e46d9749`
- 重构主题配置与样式系统，支持动态主题切换 `90c0d9ab`

### 透明度层级交互系统
- 提取聊天工具面板和悬停背景为独立可调透明度变量 `6daa5a95`
- 调整 `surfaceOpacity` 默认值为 0.5，优化 CSS 注释，添加模态框内容保护 `31e8b13b`
- 修复消息工具面板半透明支持 + 设置侧栏激活态背景 `52c7f71c`
- 添加 `bg-background-hover` 半透明支持，覆盖设置页静态背景区域 `74802ddb`
- 调整 Spider-Man 主题区块顺序，移除 emoji，优化面板遮罩 `9c1dd715`
- 背景网格增加至 4 列 `4d378c84`
- 默认深色主题背景改为纯黑，AI 回复消息背景调整 `9ad8c857`

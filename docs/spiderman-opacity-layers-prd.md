# Spider-Man 透明度层级交互 PRD

> 版本：v1
> 日期：2026-08-03
> 状态：原型/设计稿

## 1. 概述

### 1.1 目标

为 Spider-Man 沉浸主题设计一套按层级深度分组的透明度控制系统，让用户能独立调节"面板"、"内容"、"子内容"三个层级的半透明程度，实现背景壁纸与内容可读性的最佳平衡。

### 1.2 核心原则

- **按层级深度分组**，而非按功能模块分组
- **同级共享**：同一层级的元素共享同一透明度值
- **上下级分开**：父容器与子元素使用不同透明度变量
- **默认值**：出厂预设兼顾美观与可读性

## 2. 层级模型

### 2.1 三层级架构

```
┌─────────────────────────────────────────────────┐
│  L0: 面板 (Panel)                               │
│  background: bg-background-elevated             │
│  CSS: --spiderman-panel-opacity                 │
│  default: 0.55                                  │
│  ┌───────────────────────────────────────────┐  │
│  │  L1: 内容 (Surface)                        │  │
│  │  background: bg-background-surface        │  │
│  │  CSS: --spiderman-surface-opacity         │  │
│  │  default: 0.50                            │  │
│  │  ┌─────────────────────────────────────┐  │  │
│  │  │  L2: 子内容 (Child)                  │  │  │
│  │  │  background: bg-background-elevated  │  │  │
│  │  │  /secondary /tertiary               │  │  │
│  │  │  CSS: --spiderman-child-opacity     │  │  │
│  │  │  default: 0.55                      │  │  │
│  │  └─────────────────────────────────────┘  │  │
│  └───────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

### 2.2 实际渲染效果（叠加透明度计算）

透明度是**乘法叠加**的：

```
L0 面板(0.55) → 面板背景 = 55% 不透明
L1 内容(0.50) → 内容背景 = 55% × 50% = 27.5% 不透明（相对原色）
L2 子内容(0.55) → 子内容背景 = 55% × 50% × 55% = 15.1% 不透明（相对原色）
```

### 2.3 视觉层次效果

用实际颜色值 `rgb(26, 26, 31)`（c-bg-elevated）和 `rgb(37, 37, 43)`（c-bg-surface）来演示：

| 层级 | 默认值 | 叠加后颜色 | 视觉效果 |
|------|--------|-----------|---------|
| L0 面板 | 0.55 | 壁纸 × 45% + 面板色 × 55% | 较实，让面板轮廓清晰 |
| L1 内容 | 0.50 | 面板底 × 50% + 卡片色 × 50% | 半透，能看到壁纸但文字可读 |
| L2 子内容 | 0.55 | 内容底 × 55% + 子色 × 55% | 较实，与 L1 形成对比 |

## 6. 关键技术设计

### 6.1 CSS 变量定义

```css
:root[data-theme="spiderman"] {
  /* 层级透明度（新增 child 变量） */
  --spiderman-panel-opacity: 0.55;    /* L0 */
  --spiderman-surface-opacity: 0.50;  /* L1 */
  --spiderman-child-opacity: 0.55;    /* L2 */
}
```

### 6.2 CSS 规则映射

```css
/* L0 - 面板 */
[data-theme="spiderman"] [data-spiderman-panel] {
  background-color: rgb(var(--c-bg-elevated) / var(--spiderman-panel-opacity, 0.55)) !important;
}

/* L1 - 内容 */
[data-theme="spiderman"] .theme-root [class*="-surface"] {
  background-color: rgb(var(--c-bg-surface) / var(--spiderman-surface-opacity, 0.50)) !important;
}

/* L2 - 子内容（聊天区域内） */
[data-theme="spiderman"] .chat-display-root [class*="bg-background-elevated"],
[data-theme="spiderman"] .chat-display-root [class*="bg-background-secondary"],
[data-theme="spiderman"] .chat-display-root [class*="bg-background-tertiary"] {
  background-color: rgb(var(--c-bg-elevated) / var(--spiderman-child-opacity, 0.55)) !important;
}
```

### 6.3 与现有代码的兼容性

| 现有变量 | 新变量 | 关系 |
|---------|--------|------|
| `--spiderman-panel-opacity` | 不变 | 保持 |
| `--spiderman-surface-opacity` | 不变 | 保持 |
| `--spiderman-chat-tool-opacity` | → `--spiderman-child-opacity` | 改名，语义更通用 |
| `--spiderman-hover-opacity` | 移除 | 跟随 L1 |

## 7. 边界情况

### 7.1 用户调低透明度可能造成的问题

| 场景 | 风险 | 缓解措施 |
|------|------|---------|
| L0=0% | 面板完全透明，无法操作 | 滑块最小值限制为 10% |
| L1=0% | 内容完全透明，文字不可读 | 滑块最小值限制为 10% |
| L2=0% | 子内容完全透明 | 滑块最小值限制为 10% |
| L0<L1 | 面板比内容更透明，层级感错乱 | 建议性提示（非强制） |
| 所有层级=100% | 完全无透明效果，壁纸被遮挡 | 合理，但失去沉浸感 |

### 7.2 对话框保护

所有 `fixed` 定位的模态框/对话框不受透明度影响，保持完全不透明：

```css
[data-theme="spiderman"] .fixed [class*="-surface"] {
  background-color: rgb(var(--c-bg-surface)) !important;
}
```

## 关键架构修正（重要）

### 1. schema 版本策略：不升 `SCHEMA_VERSION`
`session_state.rs`（版本 2）与 `session_db.rs`（版本 1）**共用同一 `messages.db`**，各自独立检查
`PRAGMA user_version` 并「不一致 → 删库重建」。若 S1 把状态库版本升到 3，则：
- `session_db` 打开时看到 3 ≠ 1 → 删库 → `session_records`/`session_events` 全丢；
- 反过来升消息库版本会删状态库。

**决策**：新表用 `CREATE TABLE IF NOT EXISTS` 幂等补建，**不升任何版本号**；
`open()` 末尾对所有打开路径执行一次 `ensure_index_schema`（幂等）。删除重建语义保持零改动。

### 2. 投影 seq：全表 MAX+1
- 每次 upsert/delete index 行，`seq = SELECT MAX(seq)+1 FROM sessions_index`（同 Mutex 内串行安全）。
- 增量查询：`WHERE workspace_key=? AND seq > ?`。
- 不做跨表/持久化 tick：简单、够用、可重建。

### 3. 投影自动维护：事件 → 状态刷新（无需前端操作）
- `append_event`（affected>0 时）与 `try_start_conversation`（事务成功时）调用
  `refresh_index_for_conversation(conversation_id)`：按 conversation_id 反查 index 行
  → `compute_status` → 重组投影 → upsert。
- 即：**事件流自动驱动投影状态**；前端唯一需调的是「新建会话后 `session_index_register(workspaceKey, record)`」。

### 4. 不自动 backfill 存量 records（留 S5）
- 老库 `session_records` 不入 index，直到前端（或迁移）显式 `session_index_register`。
- 避免隐式推断 workspace_key 造成串桶；迁移在 S5 统一做。

## 命令面（新增，全部同步请求-响应；广播帧留 S3）

```
session_index_register(workspaceKey, record) → SessionProjection   // 幂等 upsert
session_index_list(workspaceKey)             → { sessions, lastSeq }   // 快照
session_index_list_after(workspaceKey, seq)  → { sessions }            // 增量（用户态 resync 数据源）
session_index_delete(workspaceKey, sessionId) → ()                     // 幂等
```

- 实现为 inner fn + Tauri command + Web IPC dispatch（对齐现有 `session_*` 模式）。
- 前端 session 列表 = `session_index_list`（首次）+ `session_index_list_after`（gap repair 数据源，S3 接入轮询/重连时使用）。

## 风险与控制

| 风险 | 缓解 |
|---|---|
| 删库炸弹（版本冲突） | 不升版本号，幂等建表（见 #1） |
| index 与事件非同一事务 | 接受最终一致（投影可重建）；写路径单语句 + 串行 Mutex |
| 前端旧路径不受影响 | 全部新增命令，零改既有签名 |
| 编译/测试门禁 | `cargo check --no-default-features` + 新增服务层单测 |

## 本次 S1 范围（锁定）

- `services/session_state.rs`：+sessions_index 表、+SessionProjection、+upsert/refresh/delete/list/list_after/seq、hook 自动刷新、单测。
- `commands/session_state_commands.rs`：+`session_index_*` inner + Tauri command。
- `web/api/ipc.rs`：+4 个 dispatch 分支。
- `lib.rs`：+命令注册。
- 不做：前端改动、广播帧、JSONL 迁移、内核轮询移除、（S2-S5）。

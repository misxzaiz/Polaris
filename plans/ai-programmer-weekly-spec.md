# Spec：AI 程序员一周新闻 → 交互式 HTML 周报（v1）

> 背景：2026-10-18 收集「一周 AI 程序员新闻」10 条，用户反馈「直接输出纯文本很枯燥」，希望结合 Polaris 能力做可视化呈现（2026-10-18）。
> 形态：`mcp__polaris-prd-preview__preview_html` 渲染的**自包含单文件交互式周报**（无外部依赖、可独立渲染）。
> 状态：**规划中**，未实现。

## 目标

把 10 条新闻从「枯燥文本列表」升级为「看得见、点得动」的交互式周报：

1. **数据可视化**：本周关键数字做成图（DeepSWE 榜单对比、代码合并量 12 倍增长、漏洞修复 68%）。
2. **新闻卡片化**：10 条新闻分 5 组卡片（模型竞赛 / 职业与就业 / 公司工程动态 / 技术前沿 / 开发者生态），每条可展开详情，带「对程序员的启示」。
3. **双视图切换**：卡片视图 ↔ 时间轴视图，一键切换。
4. **本周观察点**：收尾给出「本周信号」与「下周关注」（10/23 开发者大会、DeepSWE 榜、CoreWeave 融资压力）。

## 实现方案（纯前端单文件 HTML，无项目代码改动）

- **位置**：`plans/ai-programmer-weekly-2026-10-18.html`（原型落盘，方便后续复用），并通过 `preview_html` 渲染。
- **技术**：内联 CSS + 原生 JS（无框架、无外部 CDN）。深色科技风，随 `prefers-color-scheme` 自适应。
- **图表**：纯 CSS/SVG 手绘（条形图、折线图、时间轴），不引图表库。
- **交互**：
  1. 卡片 hover 抬升 + 阴影；点击展开详情（`<details>` 语义）。
  2. 视图切换 Tab：卡片 / 时间轴（JS 切换显隐，不重载）。
  3. 顶部「本周速览」数字条（10 条新闻 / 4 大事件日 / 1 场大会）。
  4. 每张卡「对程序员的启示」用高亮徽标，一眼可扫。
- **版式**：响应式栅格（宽屏多列、窄屏单列），正文中文字体系统栈，字号 ≥14px。

## 验收

1. `preview_html` 渲染后：标题/速览/图表/卡片/时间轴/观察点全部可见，无外部资源请求。
2. 卡片可展开详情；Tab 切换卡片 ↔ 时间轴正常；hover 效果生效。
3. 深色/浅色模式下文字对比度 ≥4.5:1（主要文本）。
4. 10 条新闻 + 宏观背景音全部收录，数字与搜索来源一致。
5. 周报可独立保存为单文件（复制 HTML 即可分享/存档）。

## 不做

- 不改 Polaris 前端/后端代码（纯内容产物，非功能开发）。
- 不加外部 CDN/字体/图表库（保持自包含离线可用）。
- 不发布为 `news_publish_daily` 日报（如用户后续要并入日报可再议）。

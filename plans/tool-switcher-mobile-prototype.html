PRD §9 移动端 / 触屏适配

手机浏览器 = compact 模式：ActivityBar 不渲染，入口在顶栏。右侧依次：① 顶栏 Grid2X2 tap toggle 开底部 sheet；② 44px 触控 tile 双列密排；③ 搜索过滤；④ 点选即切换并收起；⑤ 点遮罩 / Esc 关闭。

与桌面版的关键差异

  • 触发：无 hover 语义，仅 tap toggle（pointer: coarse 禁用 hover 路径）
  • 形态：顶部下拉 → 底部 sheet（自下而上 240ms，圆角顶缘 + 抓手条），拇指可达
  • 触控目标：tile 34px → 44px（WCAG 2.5.5）；顶栏按钮 38px
  • 背景遮罩：移动端加半透明 backdrop，点击关闭、防误触下层
  • 滚动：overscroll-behavior: contain，面板滚动不连带页面
  • 安全区：env(safe-area-inset-bottom) 兜底 home indicator
  • 双列网格 / 分组 / 搜索 / 「当前侧栏 + 关闭」全部与桌面一致（密度优化同样成立）

实施要点

  • compact 判定复用 useWindowManager.isCompact，不新增第三套小屏判定
  • sheet / flyout 收敛为 variant，一个组件两种外壳；数据源零改动
  • 本原型为「现状单列需滚动 + 顶栏下拉离拇指远」的对照项，桌面版见预览 v1
